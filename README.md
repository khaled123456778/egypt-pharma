# Egypt Pharma - Pharmaceutical Industries Accessories

Official corporate web platform for **Egypt Pharma for Pharmaceutical Industries Accessories S.A.E.** (Founded on 18th June 2000, 10th of Ramadan City, Egypt).

## Overview
Egypt Pharma is a leading Egyptian manufacturer of:
- **Aluminium P.P. Caps (28*18 mm)** with roll-on pilfer-proof safety bands for pharmaceutical syrups and suspensions.
- **Polyethylene (PE) Liners & Wads** manufactured from virgin German polymer (FDA 21 CFR compliant).
- **Polypropylene (PP) Plastic Closures** engineered for medical and clinical packaging.

## Technology Stack
- **Framework:** [Next.js 15 (App Router)](https://nextjs.org/)
- **UI & Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Deployment:** [Vercel](https://vercel.com/)

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm start
```
